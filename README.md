# DoremonOS

A Doraemon-inspired desktop environment and beginner-friendly Linux learning demo. Open `doremon.html` in a modern browser, then choose **Linux Learning** from the desktop or dock.

The learning path introduces `pwd`, `ls`, `cat`, `mkdir`, and `cp` through a guided project-folder mission. The terminal is simulated: these commands only affect the demo's virtual files and never run on the host computer. The built-in guide uses scripted explanations and does not call an AI service.
